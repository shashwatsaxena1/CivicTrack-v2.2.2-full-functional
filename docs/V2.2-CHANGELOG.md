## CivicTrack v2.2.1 — Public browsing + protected-action UX
- Public users can browse the dashboard, public projects, map, public issues and public evidence without being redirected to `/login`.
- Login/register is now a modal and is opened only when an authenticated action is attempted.
- After authentication, the requested protected action can continue without forcing the user through a dedicated login page.
- Added project comments with authenticated submission and audit logging.
- Public project detail responses now include published comments and enforce public visibility for unauthenticated access.
- Public complaint listing excludes complaints attached to private projects.
- API health version updated to `2.2.1`.
- Added migration `003_v221.sql` for project comments.


## v2.2.2 — public-first interaction cleanup

- Removed the dashboard showcase photo from the public landing surface.
- Removed the CONTROLLED WORKFLOW section and the PUBLIC ACCESS / Browse without an account role panel.
- Public browsing remains available directly on Dashboard, Projects, Map, Complaints, and Evidence views.
- Removed always-visible Sign in buttons from the sidebar/top bar; authentication is opened only when a protected action is attempted.
- Kept protected actions server-enforced: complaints, comments, evidence, and issue support still require authentication.
- Bumped API/web/root package version to 2.2.2.
